Automation Guide

Turn this into a live wallpaper that refreshes automatically using the free Automate app by LlamaLab.

1

Create a Flow

Download the app from the Play Store. Click the + icon to create a flow. Tap "Untitled" at the top and name it "Wallpaper".

2

Add 3 Blocks

Tap the Pencil icon at the bottom, then the Connections icon (lines). Tap + and search to add these 3 blocks:
Await time, HTTP request, and Set image wallpaper.

3

Block 1: Await time

Tap the block to edit. Set the Time of day to 12:10 AM so it updates right after midnight.

4

Block 2: HTTP request

Method: GET
Request URL: Paste the URL copied from this website here
Request content type: JSON
Save response in: Save to file
Save response path: Type Download/wall.png

5

Block 3: Wallpaper Set

Image URI: Type Download/wall.png

6

Connect & Start

Drag the "OK" dots to connect the blocks in order. Crucially, connect the "OK" dot of the final Wallpaper block back to the "IN" dot of the Await Time block to create an infinite loop! Then click Start.

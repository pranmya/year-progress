Universal URL

Your personal, dynamic endpoint. Use this link in your automation app to fetch a freshly generated wallpaper on-demand.

Automation Guide (Automate App)

Create a flow in the Automate app by LlamaLab to refresh your wallpaper daily.

⏳

Block 1: Time Await

Add a Time await block. Set the Time of day to 00:01 (Midnight). Since this is a live API, it updates instantly!

🌐

Block 2: HTTP Request

Connect to an HTTP request block.
Method: GET
Request URL: Paste your copied link
Save response path: Type Download/wallpaper.png

🖼️

Block 3: Wallpaper Set

Connect to a Wallpaper set block.
Image URI: Type Download/wallpaper.png
Important: Connect the "OK" dot of this block back to the "IN" dot of the Time Await block to make it loop forever!
